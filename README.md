# Autocue - Digital Teleprompter

A web-based digital teleprompter application built with Vue 3, TypeScript, and Vite. Autocue provides an intuitive, real-time interface for displaying and controlling on-screen text while presenting, speaking, or recording videos.

## Features

- **Real-time Text Display** - Seamlessly display and control script text on screen
- **Smooth Scrolling** - Adjustable scroll speed for natural reading during presentations
- **Responsive Design** - Works on various screen sizes and devices
- **Modern UI** - Clean, professional interface for distraction-free reading
- **Fast Performance** - Built with Vite for optimal performance and rapid development

## Use Cases

- Live presentations and speeches
- Video recording and YouTube content creation
- News broadcasts and interviews
- Educational videos and tutorials
- Podcast recordings
- Public speaking events

## Technology Stack

- **Vue 3** - Progressive JavaScript framework
- **TypeScript** - Type-safe JavaScript
- **Vite** - Next-generation build tool
- **Pinia** - State management
- **Vitest** - Unit testing framework
- **ESLint** - Code quality tool
